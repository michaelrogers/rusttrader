## Collaboration Rules

- Claim one scoped item at a time in `docs/STATUS.md`.
- Avoid parallel edits in the same UI area unless coordinated.
- Prefer small, behavior-preserving increments for refactors.
- If reality differs from docs, update `docs/STATUS.md` in the same change.
