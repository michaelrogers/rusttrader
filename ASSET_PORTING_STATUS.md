# Asset Porting Status & Practical Guide

## Current Situation

The original Space Trader Palm OS source code is available at https://github.com/videogamepreservation/spacetrader, but the **bitmap resource files (.rsrc) are not stored in Git**. They are 0 bytes because:

1. Binary resource files require Git LFS (Large File Storage) to track
2. The original repo doesn't have LFS configured
3. These files were generated by CodeWarrior, a proprietary Palm OS IDE from ~2000-2005

## Why We Can't Simply Extract Them

### The Technical Issue

The resource files contain compiled bitmap data. Extracting them requires:

**Option A: CodeWarrior Compilation**
- CodeWarrior is no longer commercially available
- Requires a ~20-year-old IDE that doesn't run on modern systems
- Even if installed, requires proper Palm SDK and environment setup
- Would need to rebuild from the source .c files

**Option B: Pre-built PRC File**
- Original game releases (.prc files) had these bitmaps compiled
- Would need to download SpaceTrader.prc from a release page
- Then use tools to extract resources from the compiled binary
- However: original releases are also hard to find

**Option C: Palm OS Emulator**
- Use CloudpilotEMU or POSE to run original game
- Screenshot/record gameplay
- Manually extract or recreate sprites
- Time-consuming but possible

## Practical Solutions (Ranked by Difficulty)

### 1. Use Existing Placeholder Assets (Current - Done)
**Status**: Already implemented
**Effort**: None
**Result**: Game is fully playable with 65 geometric placeholder sprites
**Quality**: Functional but not visually appealing
**Code**: `tools/generate_placeholder_assets.py`

### 2. Commission Custom Artwork (High Cost)
**Effort**: 10-20+ hours of art work
**Cost**: $500-$5000+ depending on artist
**Quality**: Original custom pixel art
**Recommendation**: Could do this for Phase 6 (polish/final release)

### 3. Find Previously-Extracted Bitmaps (Research)
**Effort**: 2-4 hours of research
**Cost**: Free if available
**Quality**: Original artwork, properly licensed
**Method**:
- Search for fan sites with extracted Space Trader graphics
- Check abandonware sites (legally questionable)
- Contact Alexander Lawrence (artist) - might provide pre-extracted versions
- Check Palm gaming forums/archives

### 4. Extract from CloudpilotEMU (Moderate)
**Effort**: 4-8 hours
**Cost**: Free
**Quality**: Original artwork
**Steps**:
1. Install CloudpilotEMU browser-based emulator
2. Find SpaceTrader.prc release download
3. Run in emulator and take screenshots
4. Use tool (like Aseprite) to extract individual sprites
5. Auto-trace/vectorize if needed

### 5. Use Resource Extraction Tools (Advanced)
**Effort**: 6-12 hours
**Cost**: Free (open source)
**Quality**: Original artwork, programmatic extraction
**Method**: Use palm-db-tools or PRC extraction tools
```bash
npm install -g palm-db-tools
palm-db-tools extract spacetrader.prc output/
```

### 6. Attempt CodeWarrior Compilation (Not Recommended)
**Effort**: 20-40+ hours
**Cost**: Free (tool unavailable anyway)
**Quality**: Original artwork
**Feasibility**: Very low - CodeWarrior no longer available for consumers

## Recommended Path Forward

**For Now (Development Phase)**:
- Keep using placeholder assets (game is fully playable)
- They don't affect gameplay, only visuals
- Placeholders are useful for testing UI/game mechanics

**For Release (Phase 6)**:
- Option 3 or 4: Find/extract original artwork

## Current Asset Pipeline

**What Works**:
- ✓ Placeholder generation (Python script)
- ✓ Asset loading in game (macroquad texture system)
- ✓ Fallback rendering when assets missing
- ✓ PNG format support (any PNG can be used)

**How to Replace Assets**:
Simply drop PNG files into:
```
assets/ships/       # Ship sprites
assets/icons/       # Encounter icons
assets/ui/          # System markers
```

File naming convention (from code):
- `assets/ships/flea.png` - normal ship
- `assets/ships/flea_damaged.png` - damaged variant
- `assets/ships/flea_shielded.png` - with shields
- `assets/ships/flea_shielded_damaged.png` - damaged+shields

## Summary

The game is **fully playable with placeholders**. We can upgrade to original artwork whenever:
- You find pre-extracted bitmaps online
- You commission new artwork
- You set up an emulator and extract them manually

There's **no critical blocker** - visual assets don't affect gameplay logic.
